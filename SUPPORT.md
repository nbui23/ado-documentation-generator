# Support

This project is maintained on a best-effort basis.

- Use GitHub issues for reproducible bugs and focused feature requests.
- Use the documentation under `docs/` for deployment, operations, security, and recovery.
- Do not post credentials, proprietary source code, prompts, production evidence, or unsanitized
  logs.
- Report vulnerabilities through
  [GitHub private vulnerability reporting](https://github.com/nbui23/ado-documentation-generator/security/advisories/new),
  not a public issue.
