# Security policy

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/nbui23/ado-documentation-generator/security/advisories/new).
Do not open a public issue containing credentials, source evidence, prompts, tokens, or
reproduction data from a production database.

Include the affected version, impact, a sanitized minimal reproduction, and suggested remediation.
Operators should stop publication jobs and revoke affected Microsoft Entra or Atlassian credentials
if active exploitation is suspected.
